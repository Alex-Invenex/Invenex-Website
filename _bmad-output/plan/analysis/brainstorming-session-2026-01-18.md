---

## Research Conducted

### 1. Current Site Analysis
- **URL:** portfolio.invenex.in
- **Stack:** WordPress + Elementor (heavy, slow)
- **Gaps:** No careers, no quote system, weak CTAs, no case studies

### 2. Competitor Analysis (WebAndCrafts.com)
- Next.js + React Server Components
- Video streaming, mega-menu, multi-channel contact
- 700+ projects, 600+ clients metrics
- Career page with video testimonials
- Department-filtered job listings

### 3. Technology Research
- Next.js 15 App Router (SSR, ISR, RSC)
- Tailwind CSS 4.x
- Sanity.io CMS (free tier)
- Resend for transactional email
- Framer Motion + GSAP animations
- Aceternity UI + Magic UI components

### 4. Design Trends 2026
- Dark mode as standard (not pure black)
- Glassmorphism for depth
- Micro-interactions on everything
- Bold typography (80px+ heroes)
- Generous white space
- Purposeful motion

### 5. SEO Strategies 2026
- AI Overview optimization (GEO)
- E-E-A-T focus (expertise, authority)
- Bottom-funnel content priority
- Multi-platform presence
- Schema markup (Organization, LocalBusiness)

## Key Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Domain | invenexsolutions.com | Already owned |
| CMS | Sanity.io | Free tier, visual dashboard, easy content updates |
| UI Components | Free Aceternity + Magic UI | Premium effects without cost |
| Auth | Admin dashboard only | Simple, no user accounts needed |
| Email | Resend | Modern API, generous free tier, great DX |
| Hosting | Vercel free tier | Edge deployment, easy setup |
